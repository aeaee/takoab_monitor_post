# Facebook Group Post Order Monitor 🚨

ระบบตรวจจับออเดอร์ในโพสต์กลุ่ม Facebook อัตโนมัติ พร้อมแจ้งเตือนด้วยเสียงและป๊อปอัปบนหน้าจอ Mac ทันทีเมื่อมีคอมเมนต์สั่งซื้อใหม่ที่ยังไม่มีการตอบกลับว่า **"รับออเดอร์"** จากเจ้าของโพสต์

---

## 🌟 จุดเด่น
1. **รองรับ 2 โหมด:**
   - **โหมด AI (Gemini Flash):** วิเคราะห์ความหมาย ประโยคสั่งซื้อ และการตอบรับออเดอร์ด้วย AI
   - **โหมด Local Keyword:** ตรวจจับคำว่า *"รับออเดอร์"*, *"รับยอด"*, *"เรียบร้อย"* ได้ทันทีโดยไม่ต้องใช้ API ใดๆ
2. **Persistent Login Profile:** ล็อกอิน Facebook ครั้งแรกครั้งเดียว ระบบจะจำ Session ไว้ในเครื่อง ปลอดภัยและไม่เสี่ยงต่อการโดนบล็อก
3. **ป้องกันแจ้งเตือนซ้ำ:** เก็บประวัติคอมเมนต์ที่แจ้งเตือนไปแล้วลง `notified_cache.json`
4. **Native macOS Notification:** เด้งแบนเนอร์แจ้งเตือนพร้อมเสียงระฆังแก้ว (`Glass`) บนเครื่อง Mac

---

## 🖥️ ใช้งานผ่านหน้าจอ Desktop App (แนะนำสำหรับ Windows)
คุณสามารถดับเบิลคลิกไฟล์ **`run_gui.bat`** เพื่อเปิดหน้าต่างโปรแกรมได้ทันที:
- **ตั้งค่าลิงก์โพสต์:** ใส่หรือแก้ไขลิงก์โพสต์ Facebook ได้โดยตรง (รองรับหลายโพสต์)
- **สั่งเปิด/ปิดเซอร์วิส:** มีปุ่ม **[▶ เริ่มทำงาน]** และ **[⏹ หยุดทำงาน]** พร้อมไฟแสดงสถานะ
- **บันทึกการตั้งค่า:** กด **[💾 บันทึก]** เพื่ออัปเดตลงไฟล์ `.env` อัตโนมัติ
- **Live Logs:** ดูรายงานสถานะและรอบการตรวจเช็คสดๆ บนหน้าจอ
- **ปุ่มช่วยเหลือ:** ล็อกอิน Facebook, ทดสอบเสียงแจ้งเตือน, ล้างประวัติ

## 🚀 วิธีการใช้งานแบบ Terminal / Script

### 1. กำหนดค่าในไฟล์ `.env`
เปิดไฟล์ `.env` (คัดลอกจาก `.env.example` ได้) แล้วใส่ลิงก์โพสต์และชื่อผู้ขาย:
```env
# ลิงก์โพสต์ในกลุ่ม Facebook
POST_URL=https://www.facebook.com/groups/xxxx/posts/yyyy/

# รอบการตรวจเช็ค (180 วินาที = 3 นาที)
CHECK_INTERVAL=180

# เวลาเปิด-ปิดร้าน (ระบบจะหยุดพักนอกเวลาทำการ)
OPERATING_HOURS=10:00-20:00

# ส่งอัปเดตสถานะปกติทุกรอบเข้า Telegram แบบไร้เสียง (ไม่สั่นกวนใจ)
SEND_IDLE_STATUS=true

# (สำคัญ) ชื่อโปรไฟล์เฟสบุ๊คของคนขาย/คนตอบรับออเดอร์
POST_AUTHOR_NAME=Peerawat 'A' Sukkawat

# เปิด/ปิดการใช้ AI (true = ใช้ Gemini AI, false = ตรวจคำในเครื่อง)
USE_AI=false
```

---

### 2. ตั้งค่า Telegram แจ้งเตือนเข้ามือถือ (ทางเลือก)
1. เปิด Telegram ค้นหาบอทของคุณ: `@takoab_alert_bot` แล้วกด **[Start]**
2. รันคำสั่งนี้เพื่อดึง Chat ID และทดสอบส่งข้อความเข้ามือถืออัตโนมัติ:
   - **macOS:** `./run.sh --telegram-setup`
   - **Windows:** `run.bat --telegram-setup`

---

### 3. ล็อกอิน Facebook ครั้งแรก
- **บน macOS:**
  ```bash
  ./run.sh --login
  ```
- **บน Windows:**
  ```cmd
  run.bat --login
  ```
*(ล็อกอินในหน้าต่าง Chrome ที่เปิดขึ้นมาให้เรียบร้อย แล้วกลับมากด **Enter** ใน Terminal / CMD)*

---

### 4. เริ่มเฝ้าดูโพสต์ (Watch Mode)
- **บน macOS:**
  ```bash
  ./run.sh --watch
  ```
- **บน Windows:**
  ```cmd
  run.bat --watch
  ```

---

### 4. ล้างประวัติการแจ้งเตือน (กรณีต้องการเริ่มนับใหม่)
- **macOS:** `./run.sh --clear-cache`
- **Windows:** `run.bat --clear-cache`
